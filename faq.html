RigMod FAQ — Your Questions Answered

Everything streamers ask about RigMod: what it is, whether it's safe, free, stream-proof, which versions it supports, where to download it, and how it behaves on DonutSMP.

About RigMod

What is RigMod?

RigMod is a free client-side Minecraft visual rig mod built for DonutSMP. It lets streamers and creators visually simulate winning outcomes on Blackjack tables, paper games, and 50/50 coinflips — all on their own screen. Learn more on the about page or browse the feature list.

Is RigMod safe?

Yes. RigMod is 100% client-side — it changes only what renders on your own screen and never sends modified data to the server or to other players. Download only from the official RigMod download page to avoid tampered re-uploads.

Is RigMod free?

Yes, RigMod is completely free. One universal JAR covers every supported version and both mod loaders, with no subscriptions or locked features.

Is RigMod stream-proof on OBS and Discord?

Yes. Because the rig renders inside your own client's engine, OBS, Streamlabs, and Discord game capture show the rigged visuals with zero mod menus or HUD artifacts. That design is the whole point: see it in the features.

Is RigMod a client-side mod?

RigMod is strictly client-side — no server plugin, no server FPS hooks, and other players see nothing. It works with vanilla and modded DonutSMP setups alike.

How does RigMod work?

RigMod intercepts the client-side render of DonutSMP gambling machines and replaces the visual outcome — dealer cards, paper results, or coinflip results — with a winning display. The server game still runs normally underneath; only your screen changes.

Does RigMod work on DonutSMP?

DonutSMP is RigMod's target server — every rig is tuned to DonutSMP's gambling machines: chest-GUI Blackjack, player-hosted paper games, and 50/50 coinflip duels. For machine mechanics in depth, see the DonutSMP slot machine mod page.

Download & installation questions

What Minecraft versions does RigMod support?

RigMod Universal supports Minecraft Java 1.20.1 through 1.21.10 on Fabric and Forge. The per-version compatibility table is on the versions page.

Where can I download RigMod?

Only from the official site — the rigmod.net download page. One universal JAR covers everything. Avoid third-party mirrors.

How do I install RigMod?

Drop the JAR in .minecraft/mods and launch your Fabric or Forge profile. Full walkthrough: the RigMod installation guide.

Is RigMod available on GitHub?

RigMod is distributed through rigmod.net rather than a public repository. GitHub re-uploads are unofficial and possibly modified — always use the official download.

Are there slot machine mods for DonutSMP?

Yes — RigMod is the leading DonutSMP slot machine and casino visual mod, covering slot machines, gambling machines, Blackjack, and coinflips, all client-side and stream-proof. Start with the slot machine mod page.
