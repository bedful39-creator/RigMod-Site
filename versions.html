RigMod Supported Minecraft Versions

RigMod Universal runs on Minecraft Java Edition 1.20.1 through 1.21.10, on both Fabric and Forge — one JAR covers every supported build. No per-version downloads, no legacy branches.

RigMod compatibility table

Minecraft 1.21 – 1.21.1 — Fabric ✓   Forge ✓   (RigMod Universal v4.8)

Minecraft 1.21.2 – 1.21.4 — Fabric ✓   Forge ✓   (RigMod Universal v4.8)

Minecraft 1.21.5 – 1.21.10 — Fabric ✓   Forge ✓   (RigMod Universal v4.8)

RigMod Fabric compatibility

RigMod Fabric support covers every listed version — install by dropping the JAR from the RigMod Fabric download page into .minecraft/mods and launching your Fabric profile. Fabric is the recommended loader for RigMod on DonutSMP

RigMod Forge compatibility

RigMod Forge support matches Fabric one-for-one. The same RigMod Forge download file works: place it in mods, launch your Forge profile, and the client-side rig activates. No separate Forge build exists or is needed.

RigMod NeoForge — status

RigMod NeoForge builds are not officially provided. Many NeoForge mods work on Forge-mapped loaders, but RigMod targets Fabric and Forge only — official NeoForge support may arrive with a future RigMod update. Unofficial NeoForge ports are not tested; use the official JAR.

Which Minecraft version for DonutSMP?

DonutSMP runs Java Edition 1.20.1+ — every version, every loader in the table above connects. DonutSMP RigMod compatibility is identical to the Minecraft compatibility list: if your client can join DonutSMP, it runs RigMod. The DonutSMP casino mod compatibility story is simple because the rig is client-side: it renders regardless of what plugins the server runs.

Checking your Minecraft version

  • In the Minecraft launcher, look at the bottom-right version label or the profile's version string.
  • In-game, the version appears on the main menu bottom-left.
  • Any 1.20.1+ build is supported by RigMod Universal — see the install guide.

RigMod version requirements

  • Minecraft Java Edition (not Bedrock) — RigMod Minecraft Java Edition only.
  • Fabric Loader or Forge Loader installed in your launcher.
  • No other gambling/casino mods for conflict-free use. See the install troubleshooting section.
