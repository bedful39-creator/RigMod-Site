How to Install RigMod on DonutSMP

RigMod installs like any Fabric or Forge client-side mod: download one JAR, drop it in your mods folder, launch. The whole setup takes under five minutes.

RigMod installation — step by step

1. Download RigMod

Grab the universal JAR from the official RigMod download page. It is the same file for every Minecraft version and both mod loaders — no separate RigMod Fabric download or RigMod Forge download exists, because one file covers both.

2. Open your .minecraft/mods folder

Press Win + R, type %appdata%\.minecraft\mods and hit Enter. If the folder doesn't exist yet, launch your Fabric or Forge profile once so the loader creates it.

3. Drop the JAR in — don't extract it

Move RigMod-v4.8-Universal.jar into the mods folder as-is. Extracting the archive is the most common installation mistake.

4. Launch your Fabric or Forge profile

Select the Fabric or Forge profile for your Minecraft version (1.20.1 through 1.21.10) in the Minecraft launcher and start the game. RigMod loads as a client-side mod — it never touches server files.

5. Join DonutSMP and open a machine

Join DonutSMP and open any gambling machine. The RigMod client-side visual rig activates automatically — see the feature overview for what each rig displays.

RigMod configuration guide

RigMod needs no configuration file for basic use: every rig detects the machine type you open. Advanced users can toggle individual rigs per game — the RigMod setup guide defaults work for 95% of streamers without changes.

How to use RigMod on DonutSMP

  • Blackjack: open a chest-GUI blackjack table and the visual card rig renders on your client.
  • Paper games: open a player-hosted paper game rig and winning item displays generate client-side.
  • 50/50 coinflips: duel a friend and the visual win engine renders your outcome.

Each rig runs 100% client-side: the DonutSMP server and other players receive no modified data — that is what keeps the visuals stream-proof in OBS and Discord (see the FAQ).

RigMod supported versions & compatibility

RigMod Universal supports Minecraft Java 1.20.1 through 1.21.10 on Fabric and Forge. The full per-version table lives on the versions & compatibility page. Unofficial NeoForge builds are not provided — stick to the official JAR for guaranteed compatibility.

Troubleshooting RigMod installation

  • Mod doesn't load: confirm your loader profile actually has Fabric/Forge installed — vanilla profiles ignore mods folders.
  • Crash on launch: remove other gambling mods that hook the same GUI classes (conflicts are rare but real).
  • Wrong version: verify your Minecraft version against the compatibility table.
